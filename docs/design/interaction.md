# app-fitness 产品说明（PRD · 与实现同步）

力量举主线 + 辅助（**CrossFit / Hyrox / AthX，单选或可不选**）。  
本文档按**当前小程序已实现行为**编写；设计稿 `docs/design/fitness new.pen` 作视觉参考，冲突时以代码为准。

主要代码：`miniprogram/` · 计划数据：`miniprogram/data/plan/`（真源同步自 `plans/`） · 法律文案：`docs/legal/`

---

## 1. 产品原则

1. **一条主路径，处处可退**  
   每屏一个主 CTA；退出说明后果（保存可恢复 / 放弃不保存）。
2. **默认少点**  
   建档可预填；今日选身体状态后直接开练；组间可提前开下一组。
3. **中断可恢复**  
   训练中杀进程、点关闭、系统返回 → 写草稿；今日主 CTA 为「继续未完成课次」。**今日页不提供「放弃并重新开始」**（放弃仅在训练退出 Sheet）。
4. **状态不佳不卡死**  
   「疲劳 / 不适」自动略降与精简，仍可开练。
5. **辅助不挡主线**  
   辅助日可按段完成；力量日辅项随处方展示。
6. **不补练**  
   只能练今天；过去未练即为漏练；休息日不可开练。

| 区域 | 行为 |

## 3. 主流程

### 3.1 建档 → 进入今日

```
法律免责声明 → 能力档案 → 训练习惯 → 推荐计划 → 今日
```

| 步骤 | 页面 | 主 CTA | 说明 |
|------|------|--------|------|
| 0 | 法律免责声明 | 同意并继续（须勾选） | 版本 `2026-08-08-legal`；未同意不可建档/开练；清数据或版本变更须重签；个人中心可查阅 |
| 1/2 | 能力档案 | 下一步 | 性别、年龄、身高、体重、三大项 1RM；辅助 **可选 1 项**（CF / Hyrox / AthX） |
| 2/2 | 训练习惯 | 查看推荐计划 | **训练节奏**（轻松练练 / 好好练 / 拼一把）+ 睡眠 + 身体情况 + 单次时长 |
| 选计划 | 推荐计划 | 使用此计划，进入今日 | 最多 4 套；按档案打分排序；进阶不展示「线性加重」；可长按拖动周历换休息日 |
| 落地 | 今日 | 开始训练 | 顶栏进「我的」 |

**校验：**

- 辅助：单选或可不选；旧档案 `running` 映射为 `athx`。  
- 计划名展示 ≤6 字：**挪威高频 / 线性加重 / 省时顶组 / 四天力量**。  
- 节奏影响推荐：轻松 → 偏省时/线性；好好练 → 均衡；拼一把 → 偏挪威/四天。

### 3.2 推荐计划（四套）

| id | 名称 | 练什么（摘要） | 练完会怎样（摘要） |
|----|------|----------------|--------------------|
| `strength-hybrid-mix` | 挪威高频 | 挪威波浪高频蹲推拉 + 肩背日 + 轻拉 | 恢复跟得上时三大项涨得快 |
| `strength-linear` | 线性加重 | 蹲卧 5×5、硬拉 1×5 + 肩背 | 打基础、每周稳加重（进阶不推） |
| `strength-time-efficient` | 省时顶组 | 5/3/1 + 肩背 | 时间紧也能长期涨 |
| `strength-build` | 四天力量 | 蹲 / 卧推 / 硬拉 / 肩背拆开 | 涨力同时围度更厚 |

周结构均含每周 **肩背日**（主项实力推 + 引体/背辅，短标签「肩背」）。  
辅助日：CF 短 Metcon / Hyrox 站技 / AthX（力量区带重量 + 有氧跑 + 摆荡农夫走）。

云函数 `recommendPlans` 与本地 `recommend-plans.js` 同规则；云未部署时离线兜底。

### 3.3 力量训练日

```
今日（身体状态）→ 训练（倒计时准备）→ 本组计时 ⇄ 组间休息
  → 下一组 / 下一动作 → 课次总结 → 今日·已完成
```

| 状态 | 进入 | 出去 |
|------|------|------|
| 今日待练 | — | 选身体状态 → 开始训练 |
| 本组计时 | 开始本组 / 倒计时结束 | 完成本组（需最短作业时长）→ 组间；暂停可继续 |
| 组间休息 | 完成本组 | 下一组；可 +20s；可提前开始 |
| 退出确认 | 关闭 / 系统返回 | 见 §4 |
| 课次总结 | 全部完成 | 回到今日·已完成 |

底栏：左暂停 · 中「完成本组」（未解锁显示剩余秒）· 右关闭。  
计时环与顶光：**品牌红 `#ff2d55`**，随进度增强亮度。  
训练中不提供现场加减重量（开练前身体状态已映射负荷）。

### 3.4 辅助日（CF / Hyrox / AthX）

```
今日·辅助日 → 分段计时（正计/倒计）→ 课次总结 → 已完成
```

- 底栏同力量模型；主 CTA 为完成本段 / 本组 / 本回合等。  
- 同样受最短作业时长锁定。  
- AthX 力量区按深蹲 1RM×约 70% 给出具体 kg（3×3）；有氧为轻松跑；收尾摆荡+农夫走带估算重量。  
- 退出确认与恢复同力量。

> 注：旧文档中的「纯跑步日」已由 **AthX** 替代；不再提供 `running` 辅助选项。

### 3.5 休息日 / 非今日

| 状态 | 主 CTA | 说明 |
|------|--------|------|
| 休息日 | 查看本周安排 → 周期页 | 无开始训练 |
| 非今日 | 仅预览 | 不开练、不补练 |

### 3.6 请假（只标记，不挪课，0 分）

今日可练且非休息时：底栏 **左「今天请假」（次要、较窄）· 右主 CTA「开始训练 / 继续未完成课次」（主要）**。

| 动作 | 结果 |
|------|------|
| 确认请假 | 写 leave 日志 score 0；课表不后移 |
| 撤销请假 | 仅当日可撤，恢复开练 |
| 有草稿时请假 | 确认后清草稿再记请假 |

### 3.7 训练完成度评分

分数只反映完成状态，**组间 +20s 不扣分**。

| 结局 | 分 | 称号 |
|------|----|------|
| 力量 / 辅助完成 | 100 | 今日已完成 |
| 半途（跨日草稿结算等） | 50 | 未完成全部 |
| 请假 | 0 | 今日请假 |
| 漏练 | 0 | 今日未训练 |

- 打开今日 / 周期时结算近 21 天过去槽位。  
- 一日一结局；完成后无再练。  
- 周 Tab：完成弱高亮、请假「假」、漏练「缺」。  
- 总结页副文案：「记录已保存」；总时长可展开分项。

### 3.8 训练周难度（按上周质量）

跨入新自然周时：

| 上周均分 | 决策 |
|----------|------|
| ≥ 70 | `currentWeek + 1` |
| 40–69 | 维持 |
| &lt; 40 | `currentWeek - 1`（最低 1） |

今日可提示上周均分与难度变化。

## 4. 中断与恢复

```
训练中退出/崩溃 → 草稿 → 今日「继续未完成课次」→ 回到中断处
```

退出 Sheet（半浮层）：

- 标题：要离开训练吗？  
- 左 **继续练**（主）· 右 **先离开，稍后继续** · 下 **放弃本次，不保存**  
- 点遮罩可关闭 Sheet（等同继续）

规则：

- 先离开：保留已完成组/段，今日可恢复。  
- 放弃：清草稿，今日恢复「开始训练」。  
- 同日超过 24h 未恢复：仍可继续，文案提示超过一天。  
- **跨自然日草稿**：打开 App 结算为半途（50）并清草稿，不能跨日续练。

## 5. 我的

布局：居中头像与资料 → 三大项面板 → 训练计划入口 → 训练习惯 → 底栏固定。

| 入口 | 行为 |
|------|------|
| 编辑三大项 | 回能力档案（`from=me`，保存后返回） |
| 训练计划卡 | 进周期页 |
| 编辑习惯 | 回习惯页（含训练节奏） |
| 关闭 | 返回今日 |
| 法律免责声明 | 只读查阅 |
| 清除本地数据并重新建档 | 清空档案/草稿/日志 → 重新免责声明 |

## 6. 控件级约定（实现）

### 身体状态（今日内联）

- Chip：**正常 / 疲劳 / 不适**（无独立开练确认页）。  
- 疲劳 / 不适自动略降与精简辅项后再开练。

### 最短作业时长（防秒点完成）

- 约计划时长的 30%–40%（短课最低约 15s，长课最低约 30s）。  
- 未解锁：主 CTA 显示「完成本组 Ns」类文案。

### 今日训练卡片

- 主项 / 辅助列表；副文案 **最多两行**，超出省略。

### 存储键

| 键 | 用途 |
|----|------|
| `af_profile` | 档案（含 `disclaimerAccepted` / `disclaimerVersion` / `disclaimerAcceptedAt`、habits.effort、auxiliaries、planId…） |
| `af_session_draft` | 未完成课次 |
| `af_session_logs` | 课次 / 请假日志（最多约 60 条） |
| `af_today_body` | 当日身体状态 |
| `af_ready_payload` | 开练载荷（力量） |
| `af_summary` | 总结页临时数据 |

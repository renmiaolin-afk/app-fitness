# app-fitness 交互说明

力量举主线 + 辅助（CrossFit / Hyrox / 跑步）。目标：流程能跑通、无卡点、常见便捷路径有落点。

设计稿：`docs/design/fitness new.pen`  
主流程画布在上排；**交互状态**补齐画在下排「交互状态 · 补齐卡点」。

---

## 1. 交互原则

1. **一条主路径，处处可退**  
   每屏最多一个主 CTA；退出/跳过永远可用，且说明后果（保存 / 丢弃 / 可恢复）。
2. **默认少点**  
   建档可预填；开练确认可「没变化，直接开始」；休息可跳过；组间可提前开下一组。
3. **中断可恢复**  
   训练中杀进程、点 X、切后台 → 今日出现「可恢复」；默认「继续上次」，明确提供「放弃重开」。
4. **状态不佳不卡死**  
   选「有点累 / 不适」时自动建议缩短与略降，用户仍可改回原计划。
5. **辅助不挡主线**  
   力量日可「跳过辅助，结束本次」；辅助日（跑 / CF）可提前结束段并进总结，不要求打满。
6. **周历永远可浏览**  
   休息日、已完成日、非今日预览都能点周历换天；主 CTA 随状态变，不会变成空白死页。

---

## 2. 全局导航

| 区域 | 行为 |
|------|------|
| 今日 ↔ 我的 | Tab / 顶栏切换；训练进行中进入「我的」不强制结束，返回今日仍可恢复 |
| 训练中 X | 一律进「退出确认」，禁止静默丢数据 |
| 系统返回 / 手势 | 等同 X（训练中）或上一屏（建档） |
| 周历 | 今日态下切换预览；非今日只预览，CTA 为「到那天再练」类文案，不开练 |

## 3. 主流程（能跑通）

### 3.1 建档 → 进入今日

```
能力档案 → 训练习惯 → 推荐计划 → 今日
```

| 步骤 | 画面 | 主 CTA | 旁路 |
|------|------|--------|------|
| 1/2 | `00 建档 · 能力档案` | 下一步 | 返回无上一页则退出 App/欢迎（实现定） |
| 2/2 | `00 建档 · 训练习惯` | 查看推荐计划 | 返回改档案 |
| 选计划 | `00 建档 · 推荐计划` | 使用此计划，进入今日 | 换卡重选；返回改习惯 |
| 落地 | `01 今日` | 开始训练 | 顶栏进「我的」；周历预览 |

**校验（不卡死）：**  
三大项可填 0（新手）但需二次确认；未选辅助时按「仅力量」推荐；辅助最多 2 项。

### 3.2 力量训练日

```
今日 → 开练确认 → 待开始 → 本组计时 ⇄ 组间休息
     →（多动作）下一动作 → … → 课次总结 → 今日·已完成
```

| 状态 | 画面 | 进入 | 出去 |
|------|------|------|------|
| 今日待练 | `01 今日` | — | 开始训练 → 开练确认 |
| 开练确认 | `01 今日 · 开练确认` | 今日 CTA / 状态链接 | 主 CTA → 待开始；「没变化，直接开始」同默认选项 |
| 状态不佳 | `01 今日 · 开练·状态不佳` | 身体=有点累/不适 | 自动勾缩短+略降；仍可「按原计划」 |
| 待开始 | `02 训练 · 待开始` | 确认后首组 / 休息后 | 开始本组 → 计时；±重量随时改 |
| 本组计时 | `02 训练 · 本组计时` | 开始本组 | 结束本组 → 组间休息；点暂停 → 暂停态 |
| 暂停 | `02 训练 · 暂停` | 点计时/暂停 | 继续本组；或「结束本组并进入休息」 |
| 组间休息 | `02 训练 · 组间休息` | 结束本组 | 开始下一组；+20s；可提前点开始 |
| 换动作 | `02 训练 · 下一动作` | 该动作末组结束 | 开始下一动作；或「跳过辅助，结束本次」 |
| 退出中 | `02 训练 · 退出确认` | 任意训练屏 X | 保存并退出 → 今日·可恢复；继续；不保存退出 |
| 课次总结 | `02 训练 · 课次总结` | 末动作完成 / 跳过辅助结束 | 回到今日 → 已完成；可看详细组数据 |
| 今日完成 | `01 今日 · 已完成` | 总结返回 | 周历浏览；我的 |

### 3.3 跑步日

```
今日·跑步日 → 开练确认 → 训练·跑步（热身→主段→收尾）→ 课次总结 → 今日·已完成
```

| 段 | 画面示例 | 主 CTA | 下一跳 |
|----|----------|--------|--------|
| 主段进行中 | `02 训练 · 跑步` | 结束主段 | 进入收尾 |
| 收尾 | `02 训练 · 跑步·收尾` | 完成本次跑步 | 课次总结（指标换成分段时长/主观轻松度） |
| 中途退出 | 同 `退出确认` | 保存并退出 | 今日·可恢复（记录已完成段） |

便捷：主段未满也可结束进收尾；收尾可跳过直接总结。

### 3.4 CF 日

```
今日·CF日 → 开练确认 → CF·技能 →（力量段）→ 训练·CF Metcon → 课次总结 → 已完成
```

| 段 | 画面 | 主 CTA |
|----|------|--------|
| 技能 | `02 训练 · CF·技能` | 进入力量段（可提前） |
| Metcon | `02 训练 · CF` | 完成 Metcon |
| 任意段退出 | `退出确认` | 保存已完成段 |

便捷：技能/力量可「跳过本段」；Metcon 可中途完成（For Time 记已用时）。

### 3.5 休息日 / 非今日

| 状态 | 画面 | 主 CTA | 说明 |
|------|------|--------|------|
| 休息日 | `01 今日 · 休息日` | 查看本周安排（描边） | 无「开始训练」；提示从周历补练预览 |
| 非今日 | `01 今日 · 非今日预览` | 回到今日 / 仅预览 | 不开练，避免改错日 |

## 4. 中断与恢复（防卡点）

```
训练中任意退出/崩溃
        ↓
  写入「未完成课次」草稿
        ↓
  再次打开 → 01 今日 · 可恢复
        ↓
  ┌─ 继续上次训练 → 回到离开时的屏（组/段进度）
  └─ 放弃未完成课次，重新开始 → 清草稿 → 开练确认或待开始
```

规则：

- **保存并退出**：保留已完成组/段；未做动作标为未完成，可续做。  
- **不保存，直接退出**：二次文案已在 Sheet 内；清草稿，今日恢复「开始训练」。  
- **超过 24h 未恢复**：今日仍显示可恢复，但文案改为「超过一天的未完成课次」，继续或放弃二选一，不自动开练。

## 6. 控件级约定

### 开练确认

- 三问：身体 / 时长 / 强度。  
- 默认全「正常·照常·按计划」。  
- 「没变化，直接开始」= 提交默认值，少一次确认。  
- 「不适」：默认「只做主项」+「保守」，并弱提示考虑休息（不强制）。

### 力量执行

- ±2.5kg 即时生效，写入本组。  
- 结束本组 → 自动进组间；最后一组 → 下一动作或总结。  
- 组间倒计时结束可轻震动；允许提前「开始下一组」。

### 跑步 / CF

- 段进度用 3 点表示；当前段高亮。  
- 正计时 / 倒计时旁标注「已用时」或「剩余时间」。  
- 主 CTA 动词对齐当前段（结束主段 / 完成本次跑步 / 完成 Metcon）。

### 我的

- 「编辑」三大项 / 习惯 / 能力：改完可提示「是否重新匹配计划」，默认否（避免打乱进行中周期）。  
- 进行中课次时编辑重量：只影响之后组，不回溯已完成组。

## 7. 便捷路径清单（验收用）

- [ ] 建档全程可返回修改，选计划后进今日有课可练  
- [ ] 今日「没变化直接开始」两步内进到第一组待开始  
- [ ] 力量：待开始 → 计时 → 休息 → 下一组 → 换动作 → 总结 → 已完成  
- [ ] 力量：跳过辅助可进总结  
- [ ] 跑步：主段 → 收尾 → 总结；中途结束主段仍可收尾  
- [ ] CF：技能 → … → Metcon → 总结；可跳过技能  
- [ ] 训练中 X → 保存退出 → 今日可恢复 → 继续到原进度  
- [ ] 放弃未完成 → 可重新开练，无死链  
- [ ] 暂停 → 继续 / 直接结束本组  
- [ ] 休息日无「开始训练」主按钮，周历可切走  
- [ ] 非今日仅预览，不能误开练  
- [ ] 状态不佳自动建议缩短，仍可按原计划

## 8. 实现备注（给开发）

- 训练栈建议独立全屏路由；总结后 `replace` 回今日已完成，避免返回键回到计时。  
- 草稿键：`userId + date + sessionId`；保存退出写草稿，课次总结成功后清草稿并写正式日志。  
- 跑/CF/力量共享 Exit Sheet 与 Pause 组件，只换文案与进度模型（组 vs 段）。  
- Hyrox 日交互对齐 CF（分段 + Metcon/站点计时），画面可复用 CF 状态行，文案改为站点。
